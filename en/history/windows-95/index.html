WHAT YOU CAN EXPLORE

A desktop for organizing and acting.

  • Double-click My Computer, Notepad, Paint, Calculator and Minesweeper.
  • Open Start and see how it brings applications and controls together.
  • Move, minimize, maximize and close demo windows.

SCOPE AND SOURCES

The teal palette, gray bevels, Start and taskbar belong to this historical scene; VoyagerOS presentation and navigation keep their own aurora visual direction.

Everything happens inside this page: files and controls are simulated, Notepad text is temporary, and Save As does not download files. The demo does not read or modify Windows or the device.
