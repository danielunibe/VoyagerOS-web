WHAT YOU CAN EXPLORE

More than a window: a desktop with identity.

  • Start menu, taskbar and switching between windows.
  • An Explorer view with sample folders and files that exist only in the demo.
  • Notepad, Calculator, Paint, Minesweeper, Solitaire, a media player and simulated web pages.

SCOPE AND SOURCES

Menus, files, messages, figures and applications are sample content. The demo does not read hardware, memory or network data, visit external sites, or download files. The calculator handles arithmetic only; messages are rendered as text.

The rolling-hills scene is drawn as an embedded vector to avoid loading remote images. The blue palette and Start menu belong to this scene; the website keeps its own aurora design.
