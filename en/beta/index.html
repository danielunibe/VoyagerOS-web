01 / What we are building

A proposal that keeps growing.

In beta

Dock & Start

The native Dock provides access to apps and controls. Start and search continue to evolve in development.

In development

Desktop organization

Visual groups, layout and tools for files. Integration and testing of the complete experience are ongoing.

In development

System controls

The Orb provides a surface for controls. Its operational scope depends on Windows providers and the available hardware.

In beta

Personalization & settings

The beta includes a native Settings window. Materials, presentation and controls are being developed progressively.

Compatibility & requirements

Development targets Windows x64. Supported Windows versions, graphics requirements and signing status will be published alongside the validated package.

What to expect at this stage

The interface and its features are evolving. Current work includes visual validation, physical interaction, installation and recovery. Images show specific development snapshots.

Towards version 1

Next come testing the complete experience, preparing the public package and writing user documentation. We will publish verifiable progress as it happens.
