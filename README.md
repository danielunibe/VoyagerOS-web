# VoyagerOS

[Visit the website](https://danielunibe.github.io/VoyagerOS-web/) · [Español](https://danielunibe.github.io/VoyagerOS-web/es/) · [English](https://danielunibe.github.io/VoyagerOS-web/en/)

A desktop experience for Windows in development. This repository contains the static public website. The native application source is maintained separately.

## Current public state

- Bilingual journey through desktop-interface history, an independent 1984 Macintosh educational study, and a 52-capability catalog.
- Development updates and RSS feeds.
- Public beta download is being prepared.
- Voluntary support via Buy Me a Coffee will be activated after the recipient profile is ready.
- 2027 is a design horizon, not an announced release date.

Historical illustrations are original educational compositions. Native captures show dated development snapshots; see the website’s Sources and Credits page. Fonts are distributed under SIL Open Font License.
