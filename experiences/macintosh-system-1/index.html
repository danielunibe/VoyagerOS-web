1984 — Macintosh
A desktop shaped by windows, icons and menus

The Macintosh helped bring a graphical desktop to a wider personal-computing audience. Earlier work, including the Xerox Alto, Xerox Star and Apple Lisa, shaped ideas that came before it.

About this prototype: This page combines a period-inspired desktop with educational interactions. It is not original Macintosh System Software, an exact reconstruction, or an Apple product.

Try: Open the Finder-style windows, compare typed commands with pointing and clicking, edit the sample document, or draw in the MacPaint-style canvas. Actions stay inside this web page and never access files on your computer.
