Qué sucede al recorrer esta web y al usar sus servicios externos.

Actualizado: 25 de octubre de 2026.

La web

Este sitio es una publicación estática alojada en GitHub Pages. La aplicación de la web no incorpora analítica, formularios de correo, cuentas de usuario ni cookies de seguimiento propias. Las tipografías y las imágenes se sirven desde el mismo sitio.

GitHub Pages

GitHub puede registrar datos técnicos de las visitas, como la dirección IP, para operar y proteger el servicio. Sus prácticas se describen en su aviso de privacidad.

GitHub Privacy Statement

Buy Me a Coffee

El perfil de apoyo está en preparación. El widget solo se activará cuando exista una cuenta receptora configurada y el visitante elija cargarlo. Al hacerlo, el navegador se conectará a Buy Me a Coffee y sus servicios de pago. Sus condiciones y políticas se aplicarán a esa interacción. Esta web no recibe ni almacena números de tarjetas o datos bancarios.

Buy Me a Coffee · Privacy

Enlaces y seguimiento

Los enlaces a fuentes históricas, GitHub y otras páginas abren servicios externos. Seguir el feed RSS de este sitio no requiere proporcionar un correo electrónico. Los comentarios públicos en GitHub quedan sujetos a las condiciones y la visibilidad de esa plataforma.

Contacto sobre el sitio

Puedes abrir una consulta sobre esta web en su repositorio público. Evita incluir información personal o archivos privados en una consulta pública.
