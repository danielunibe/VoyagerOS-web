2001 / ESTUDIO INTERACTIVO

Un escritorio que hizo familiar la computadora.

Explora la interfaz que compartiste: una escena didáctica independiente inspirada en Windows XP. Presenta un escritorio azul, el menú Inicio y varias aplicaciones simuladas; no es software de Microsoft ni una reconstrucción verificada.

LO QUE PUEDES EXPLORAR

Más que una ventana: un escritorio con identidad.

  • Menú Inicio, barra de tareas y cambio entre ventanas.
  • Explorador con carpetas y archivos de ejemplo que viven solo en la demo.
  • Bloc de notas, Calculadora, Paint, Buscaminas, Solitario, reproductor multimedia y páginas web simuladas.

ALCANCE Y FUENTES

Los menús, archivos, mensajes, cifras y aplicaciones son contenido de muestra. La demo no lee hardware, memoria ni red, no visita sitios externos y no descarga archivos. La calculadora evalúa solo operaciones aritméticas; los mensajes se muestran como texto.

El paisaje de colinas está dibujado como vector dentro del archivo para evitar cargar imágenes remotas. La paleta azul y el menú Inicio pertenecen a esta escena; la web mantiene su propio diseño aurora.
